History

Frame does not record browsing history yet. Not as a feature — there is simply no store behind this page. Nothing has been kept, so there is nothing to show you.

  • Per tab Back and forward already work, from Chromium's own in-memory navigation list. Alt+Left and Alt+Right.
  • On disk Nothing is written. When it is, it will be local, readable, and deletable from here.
  • Incognito Will never be recorded, whatever this page grows into.

Ctrl+H opens this page.
