Settings

Nothing here is configurable yet. What the browser already does, it does because the code says so — these are the switches that will expose it.

  • Telemetry Already off, and never initialised rather than disabled after the fact. This page will show exactly which Chromium switches are applied.
  • Safe Browsing Off. Its real-time mode sends visited URLs to Google, so it will be an explicit opt-in with the tradeoff spelled out — not a default.
  • Search engine Google, hardcoded in the omnibox rule.
  • Tracker blocking Part of the privacy layer, not yet built.
  • Request contexts Per-tab isolation, not yet built. Incognito windows already get their own in-memory context.
